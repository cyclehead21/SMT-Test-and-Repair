## Materials

2” steel box section, thin wall

11” inch long steel rod, ⅞ inch diameter (2 each)

⅞ inch ID thin wall pipe sections (2 each)

1” ID Big fat washers (4 each)

Hitch “receiver” \*

Hitch pins (2 each) \*

(\*) Available from AgriSupply or Tractor Supply

The ⅞ inch ID thin wall pipe was ordered from Aircraft Spruce Company (1 inch OD with .058 wall thickness)

[https://www.aircraftspruce.com/catalog/mepages/4130tubing_short.php](https://www.aircraftspruce.com/catalog/mepages/4130tubing_short.php)

Cut, assemble and weld as photos show.

Don’t buy an M22x2 die. A good machine shop will be able to cut the threads on a lathe.

This “SDS Plus” extension is supposed to have the correct M22x2.0 thread. It might be possible to use it to fab some cheaper rods. Maybe hard to cut tool steel!

https://a.co/d/fhyokgt

Note the sloppy holes cut in the box section, this is intentional. It allows the threaded rod to have some movement. I’ve read that the center-to-center distance between towing eyes is slightly different from car to car.

Note that the threaded rods will REST ON THE STEEL CRASH BAR PENETRATION HOLES. This is intentional as it avoids applying a twisting/prying load on the threaded towing eye nuts. Those nuts are not welded very soundly by Toyota. The green arrows show where the rod rests on the crash bar to help distribute any tongue weight on the hitch.
